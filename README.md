# WFProdutos
Tela C# Windows Forms para testar WebService zWSProdutos

Meu nome é Molina, sou um Analista desenvolvedor do Protheus.

Criei uma tela em Windows Forms para testar o Rest de criação de Produtos do Protheus, tabela SB1, disponibilizada pelo programa zWSProdutos do curso de WebServices do Terminal de Informação.

O propósito é básico: testar o serviço além do teste via Postman.

A tela pede Código, Descrição, Tipo, Unidade de Medida, Armazém padrão e Grupo, o que esta especificado no zWSProdutos.

Criei um WebService denominado zWSChaves para trazer do Protheus a relação dos Tipos, Unidades, Armazéns e Grupos, concordo que num uso "real" seria melhor estas informações virem direto de outro banco e não ao abrir uma tela mas o meu objetivo é apenas didático e para testes.

Espero que possam melhorar o que fiz e disponibilizar também, já trabalhei com Clipper, Visual Basic e um pouco de C# Sharp, mas já faz um bom tempo, ultimamente mais suporte e sustentação

O Webservice de Chaves pode ser expandido para outras relações, tabelas e usos

Gostaria de agradecer muito o Atílio do Terminal de Informação
